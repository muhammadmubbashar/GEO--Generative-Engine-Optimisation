4. A fair before-and-after comparison

The diagram shows two reading packs. One contains the baseline Flight Centre page and the other its improved representation. We match the question, source identities, source order, competitor text and instruction. We do not require the AI to cite Flight Centre. Twenty-nine questions had a Flight Centre page in the selected source pool, so those were eligible for this comparison. Repeated answers help us see whether the result varies. Our baseline answers were generated earlier; they were not generated at the same time as the treatment. That is a limitation, because changes over time could also affect results. We kept the original records so this comparison can be checked.

5. What we tried separately

We explored six approaches before choosing a combined page. Rendering and cleanup expose useful captured information and make it readable. Questions and answers keep related information together. Structured facts organise existing details. External information adds attributed material from outside the page. Schema adds labels intended for software. Automatic rewriting changes the wording more broadly. The tests did not all produce clear gains. Questions and organised facts were encouraging. Rendering and external information had more uncertainty. The schema experiment also changed visible text, so we cannot isolate schema’s effect. The reviewed automatic rewrite performed worse. Exact numbers and intervals remain in the evidence package; this slide summarises what we learned.

6. What we combined

The final page combines a smaller set of compatible changes. We expose captured rendered information, clean up its text, organise supported travel information, and preserve useful question-and-answer relationships. We did not combine every experiment. Added external enrichment, added schema, broad rewriting and moving the whole source to the front stayed separate. Selecting components is a design decision informed by evidence. It does not prove that each component caused a particular share of the final gain. The combined page therefore needed its own test. We can inspect the output and trace it back to the implementation.
